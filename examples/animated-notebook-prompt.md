# End-to-end demonstration prompt

Use Notebook Forge to create notes about TCP three-way handshake, binary search
and a simplified water cycle. The notebook theme and dedicated topic pages are
confirmed for this demonstration. Include an original locally drawn animation
inside each core explanation, using three different layouts and progression
patterns. Include captions and alternative descriptions. Deliver companion HTML
with GIF assets and a searchable PDF with stills. Run both GIF verification passes
and both ruled-page checks. Report any viewer limitation honestly.

`tools/create_animation_demo.py` authors the job, and
`scripts/render_animated_notes.py` builds it. No AI service is needed by these
local scripts; an agent authors and audits the explanations and storyboards.
