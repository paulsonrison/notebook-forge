# Notebook Forge v1.1.0 — Illustrated learning notes

Create notes students can understand visually: when images are approved, every
topic and subtopic now requires at least one original, relevant teaching image.
PDFs embed these static images directly. GIFs remain an optional HTML feature.

- Ask separately for image and GIF permission before generating either kind.
- Place every original image immediately after its exact host explanation,
  with a descriptive caption and alt text. No unrelated galleries or filler.
- Enforce topic coverage, local paths, valid PNGs, unique files/pixels/layouts,
  exact heading/topic mappings and changed-asset detection in the manifest.
- Require technical verification, then a recorded topic-alignment/readability
  audit of both source images and rendered PDF pages.
- Remove stale generated assets when a notebook's media choices change.
- Include a verified three-topic static image demo: TCP handshake, binary search
  and the water cycle, with actual images embedded in PDF and companion HTML.
- Preserve existing text-only jobs, themes, layout choices, ruled-text masks,
  source links, searchable text and optional GIF verification.

Use `render_notes.py` and `verify_media.py`. Existing bundle and GIF command names
remain compatibility aliases. Existing GIF jobs must now record actual consent.
Never copy demo permission flags into a real notebook without the user's choice.
