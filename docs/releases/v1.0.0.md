# Notebook Forge v1.0.0 — Animated learning notes

Notebook Forge now creates original, topic-specific animated GIFs locally and
places them immediately after the matching explanation in companion HTML.
PDFs retain searchable text and show meaningful still frames with captions and
alternative descriptions. PDF pages themselves do not animate.

- Original storyboards, no external GIF downloads or hotlinks.
- Unique concepts, compositions and progressions tracked in an asset manifest.
- Technical integrity/uniqueness gate, followed by an explicit visual and topic
  alignment audit bound to the exact job, generator and assets.
- Readable keyframe timing, final pauses, clear labels and reduced-motion stills.
- Fixed ruled-page text overlap; structural and raster checks protect captions,
  paragraphs, labels and continuation pages.
- Three-topic demo: TCP handshake, binary search and the water cycle.
- Updated notebook/play icon and self-contained plugin metadata.

Requires Python 3.10+, ReportLab and Pillow. PDF raster QA additionally uses
pdfplumber and pypdfium2. Existing PDF-only jobs and theme/layout choices remain
supported. Educational correctness and honest visual-review evidence cannot be
established by hashes alone.

Install/update the plugin using the instructions in README.md. Keep the HTML
file beside its `assets/gifs/` directory when sharing animated notebooks.
