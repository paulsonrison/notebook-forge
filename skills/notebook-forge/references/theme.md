# Visual guide

The default theme is independently drawn, not a copied or embedded screenshot.
Ask the user to choose it for each new notebook before drafting.

| Element | Default |
|---|---|
| Paper | Warm ivory #FFFEF6, A4 portrait |
| Rules | Pale cyan #D6EDF0, 19-point spacing |
| Margin | Red vertical line, left of the content |
| Ink | Dark blue #193963 |
| Titles | Comic Neue Bold, yellow highlighter #FFF068 |
| Labels | Alternating pastel pink #F9D9EF and mint #C9F5DE |
| Numbers | Red circled section numbers |
| Examples | Light blue bordered code panel |
| Recall prompts | Pale yellow panel |
| Body | Embedded Bitstream Vera, at least 11 points |
| Code | PDF core Courier, at least 9.5 points; ASCII examples |

Use a main title, short introduction, key points, worked example, common pitfalls
and recall/practice prompt where the subject supports them. These are useful
defaults, not mandatory filler. A data-heavy document can use different labels.

Plain mode removes the rules and coloured fills but keeps readable hierarchy.
Custom mode accepts the palette keys documented in the job contract. For a
reference requiring a different composition, adapt the renderer or use another
appropriate PDF tool; do not promise arbitrary image reproduction from a palette.

Preserve comfortable whitespace. Every topic/subtopic page should teach
something useful; an overview page must contain orientation, not just a title.
Long content continues on additional pages. Extra pages are allowed by "at least
a page"; a strict user page limit needs editorial reduction, not unreadable type.

The bundled Comic Neue font is SIL OFL licensed; see assets/fonts/OFL.txt.
ReportLab supplies Bitstream Vera with its own license. Do not copy fonts from
a user's operating system into a shared package without a distribution license.
