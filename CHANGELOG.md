# Changelog

## 1.0.0 — 2026-11-16

- Generate original local GIFs from custom topic-specific storyboards using
  Pillow. No web GIF fetching, hotlinking or stock-animation dependency.
- Embed each animation immediately after its host explanation in companion
  HTML; retain a final-state still, caption and alt text in searchable PDFs.
- Enforce unique concepts, paths, section mappings, compositions, progression
  descriptions, file hashes, decoded visuals and storyboard geometry.
- Add readable timing, final pauses, contrast/font/bounds checks, reduced-motion
  stills, decoded contact sheets and a manifest for each notebook.
- Require technical verification followed by a recorded, hash-bound alignment
  and readability audit. Regeneration invalidates stale reviews.
- Fix blue rules crossing text by masking rules beneath text-bearing areas,
  including continuation paragraphs and labels. Add structural and raster QA.
- Include a three-topic animated demonstration and an aligned notebook/play icon.
- Preserve previous jobs, themes, layout confirmations, searchable text,
  bookmarks, sources, long code and continuation-page workflows.

PDF remains static; motion is supported by the companion HTML and GIF assets.
Semantic accuracy and visual audit evidence require actual agent/editor review.
